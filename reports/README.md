# reports/

Generated QA deliverables, per product and run:

```
reports/<product>/<run-id>/strategy.md
reports/<product>/<run-id>/qa-execution-report.md
reports/<product>/<run-id>/traceability-matrix.csv
reports/<product>/defects/DEF-<PROD>-001.md      (drafts; filing needs approval)
```
Templates are in `templates/`. Reports are produced by the Senior QA Supervisor and accepted at gate G4.
