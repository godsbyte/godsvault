# templates/

Standard QA templates. Changes to these are shared-standard changes and need human approval.

| File | Purpose |
|---|---|
| `product-profile.md` | Product onboarding profile (→ `products/`) |
| `test-strategy.md` | Test strategy and risk assessment |
| `test-case.md` | Scenarios, test cases, exploratory charters |
| `defect-report.md` | Draft defect |
| `qa-execution-report.md` | Final QA report |
| `traceability-matrix.csv` | Requirement-to-defect matrix |
| `run-log.md` | Append-only execution log |
