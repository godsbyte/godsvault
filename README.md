# Enterprise QA Supervisor

Supervisor-led multi-agent QA system for GitHub Copilot. Start with the **`senior-qa-supervisor`** agent (`/agent` in Copilot CLI) and provide a product, app URL, repo, and ticket.

- Architecture and folder map: `supervisor agent/architecture.md`
- Who does what: `supervisor agent/responsibility-matrix.md`
- Orchestration and gates: `supervisor agent/orchestration-workflow.md`
- Illustrative walkthrough: `supervisor agent/sample-execution.md`
- Standards: `instructions/` · Skills: `skills/`, `global skills/` · Templates: `templates/`
